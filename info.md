# Ubiquiti AirOS (HTTP)

Home Assistant custom integration for legacy Ubiquiti airOS 4.x devices, using the device's local HTTP web interface.

- **Domain:** `airos_xs2`
- **Target firmware:** `XS5.ar2313.v4.0.4.5074.150724.1344`
- **Communication:** Local HTTP polling (credentials and traffic are not encrypted)
- **Documentation:** https://github.com/jonny5509/ha-airos-http
- **Issues:** https://github.com/jonny5509/ha-airos-http/issues

This integration is community-maintained and is not affiliated with Ubiquiti. Compatibility and available sensor data depend on the device's firmware and HTTP responses.
